Aplicativo de optimización

Método gráfico, teoría de colas y cadenas de Markov. Modifique cualquier dato y el resultado se recalcula al instante. Ejemplo precargado: cafetería universitaria (datos ilustrativos).

Datos del modelo

Programación lineal con dos variables (x₁, x₂ ≥ 0). Ejemplo: cuántos sándwiches y wraps producir al día; utilidad en miles de COP.

Objetivo

Restricciones a₁x₁ + a₂x₂ (op) b

Escenario «¿y si…?»

Cambie el lado derecho de una restricción y compare con el óptimo base. Estima el precio sombra ΔZ/Δb.

Datos del sistema
